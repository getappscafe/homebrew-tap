# getapps.cafe Homebrew tap

Mac apps from [getapps.cafe](https://getapps.cafe). Each app comes with a getapps.cafe membership (7-day free trial).

```sh
brew install --cask getappscafe/tap/sheetcafe
```

| Cask | App |
|---|---|
| `bookcafe` | [BookCafe](https://getapps.cafe/app/bookcafe) - Write books in chapters and export to web, PDF or EPUB |
| `brewcad` | [BrewCAD](https://getapps.cafe/app/brewcad) - Viewer and editor for DWG and DXF drawings |
| `cremastudio` | [CremaStudio](https://getapps.cafe/app/cremastudio) - Photo editor with layers, masks and filters |
| `designbrew` | [DesignBrew](https://getapps.cafe/app/designbrew) - Offline design and technical drafting tool |
| `doccafe` | [DocCafe](https://getapps.cafe/app/doccafe) - Word processor for DOCX documents |
| `fontsiphon` | [FontSiphon](https://getapps.cafe/app/fontsiphon) - Preview installed fonts and turn families on or off |
| `resumeroast` | [ResumeRoast](https://getapps.cafe/app/resumeroast) - Resume and CV builder with PDF export |
| `sheetcafe` | [SheetCafe](https://getapps.cafe/app/sheetcafe) - Spreadsheet editor for XLSX, XLS and CSV files |
| `snapbrew` | [SnapBrew](https://getapps.cafe/app/snapbrew) - Snap windows into place by drag, shortcut or menu bar |
| `steepjournal` | [SteepJournal](https://getapps.cafe/app/steepjournal) - Private diary encrypted with your own password |

Casks are generated from the apps' version manifests (`https://getapps.cafe/app/<slug>/version`).
